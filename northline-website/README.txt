Northline — Independent product design studio website
=====================================================

Open index.html in a browser.

Pages:
  index.html          Home
  work/               Project list + case studies
  approach.html       Process
  notes/              Essays
  contact.html        Contact form
  styles.css          Design system
  og.jpg              Link preview (1200x630)
  favicon.svg

Free hosting: Netlify Drop, Cloudflare Pages, or GitHub Pages.


Notes for deployment:
- The contact form is configured for Netlify Forms. Deploy the site to Netlify to receive submissions.
- On GitHub Pages or another static host, replace the contact form backend with your preferred form service/serverless endpoint.
- The site uses Google Fonts; for a fully self-hosted build, self-host Figtree and Instrument Serif.
