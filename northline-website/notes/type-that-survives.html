Type that survives a decade

Fashion in a UI is a tax the next team has to pay.

We set interfaces in a small number of sizes, a single family with a real italic, and a measure you can hold. That is not nostalgia. It is maintenance.

A product that launches with a display face from this year’s landing-page trend will look dated before the second contract is signed.

Choose type that was designed to be read. Pair it with a tabular cut for numbers. Do not letter-space lowercase.

If the type is right, you can restyle the chrome in five years and the product will still feel like itself.
