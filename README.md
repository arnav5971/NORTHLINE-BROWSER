# North Browser 2.0
A polished Android WebView browser starter with a professional UI and practical features.

## Features
- Secure HTTPS-first navigation and Google search fallback
- Address bar, loading progress and pull-to-refresh
- Back, forward, home and reload controls
- Bookmarks and local history
- Desktop-site toggle
- Share current page
- Private session mode that avoids saving history
- Clear browsing data
- GitHub Actions workflow for debug APK builds

## Build
Push this project to GitHub and run the included workflow, or open it in Android Studio and build `assembleDebug`.
